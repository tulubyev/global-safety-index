# World Safety Index — методология расчёта

Документ описывает, как из открытых источников получается итоговый балл страны.
Соответствует коду на момент последнего обновления (см. дату внизу).

---

## 1. Итоговая формула

Единственная реализация формулы — [`backend/src/services/scoreService.js`](backend/src/services/scoreService.js),
её зеркало для клиента — [`frontend/src/lib/score.ts`](frontend/src/lib/score.ts).
Все потребители (карта, рейтинг, панель страны, cron) обязаны считать через них.

```
raw   = Σ wᵢ × dimᵢ                  // веса нормализованы до суммы 1, каждое dimᵢ ∈ [0, 100]
score = √(raw / 100) × 100           // абсолютная шкала 0–100
```

Ключевое свойство — **шкала абсолютная**, а не относительная. Балл страны
не зависит от того, какие другие страны попали в выборку. Поэтому:

- один и тот же балл в списке, на карте и в карточке страны;
- исторический график имеет смысл — прошлые значения не «плывут» при
  изменении ситуации у соседей;
- корень растягивает нижнюю часть диапазона, иначе спокойные страны
  сжимались бы в неразличимый ноль несколькими экстремумами.

`0` — минимальный риск, `100` — максимальный.

### Веса по умолчанию

| Измерение | Вес | Ключ |
|---|---|---|
| Вооружённый конфликт | 30 % | `conflict` |
| Стихийные бедствия | 20 % | `disaster` |
| Продовольственная безопасность | 20 % | `food` |
| Сейсмическая активность | 10 % | `seismic` |
| Пандемический риск | 20 % | `pandemic` |

Пользователь меняет веса слайдерами; сервер нормализует любой набор
неотрицательных чисел до суммы 1 (`POST /api/custom-weights`).

## 2. Измерения

### 2.1 Conflict — вооружённый конфликт (30 %)

**Источник: UCDP GED** — Uppsala Conflict Data Program, Georeferenced Event Dataset.
Парсер: [`backend/src/parsers/ucdpParser.js`](backend/src/parsers/ucdpParser.js)

- Годовой релиз GED (`ged<VV>1-csv.zip`, ~29 МБ) + ежемесячные *candidate events*
  за годы после его покрытия. Версия определяется автоматически пробой HEAD-запросом.
- Учитываются события с `year >= 2020`, берётся поле `best` (наиболее вероятная
  оценка числа погибших). События дедуплицируются по `id`.
- Экспоненциальное затухание по `date_start`, **период полураспада 2 года**:
  свежие потери весят больше давних.
- Страна: `country_id` (номер Gleditsch–Ward) → ISO2 по таблице в парсере,
  затем алиасы UCDP, затем имена из таблицы `countries`.
- Затем **min-max нормализация** по всем странам с данными → 0–100.

Лицензия CC BY 4.0, ссылка обязательна: Davies, Pettersson & Öberg,
*Organized violence 1989–2025*, Journal of Peace Research, 2026.

**Резерв — ACLED.** Подключается, только если заданы `ACLED_EMAIL`/`ACLED_PASSWORD`.
На практике `acleddata.com/oauth/token` закрыт Cloudflare-челленджем для
серверных IP и отвечает `403` до проверки учётных данных, поэтому основным
источником сделан UCDP.

### 2.2 Disaster — стихийные бедствия (20 %)

Смесь структурного индекса и текущих событий:

```
disaster = 0.70 × INFORM(наводнения, циклоны, засухи, цунами) + 0.30 × ReliefWeb(активные бедствия)
```

- **INFORM Risk Index** (EU JRC), [`informParser.js`](backend/src/parsers/informParser.js) —
  среднее четырёх суб-индексов (каждый 0–10) × 10 → абсолютная шкала 0–100, 191 страна.
  Землетрясения **исключены намеренно**: они учитываются в `seismic`, иначе
  сейсмика считалась бы дважды.
- **ReliefWeb Disasters**, [`reliefwebParser.js`](backend/src/parsers/reliefwebParser.js) —
  статусы `ongoing`/`alert` за 3 года, вес по типу бедствия (цунами 2.0 …
  пожар 0.7), затухание с периодом полураспада 1 год, затем min-max.
  Эпидемии из этого набора исключены — они идут в `pandemic`.

### 2.3 Food — продовольственная безопасность (20 %)

**World Bank `SN.ITK.DEFC.ZS`** — доля недоедающего населения, последний доступный год.
Парсер: [`worldBankParser.js`](backend/src/parsers/worldBankParser.js). Min-max → 0–100.

### 2.4 Seismic — сейсмическая активность (10 %)

```
seismic = 0.80 × INFORM(earthquake) + 0.20 × USGS(события за 30 дней)
```

- **INFORM earthquake** (0–10 → 0–100) — структурная сейсмическая опасность,
  191 страна. Это основа: опасность землетрясений определяется тектоникой,
  а не тем, тряхнуло ли в конкретном месяце.
- **USGS** M4.5+ за 30 дней, [`usgsParser.js`](backend/src/parsers/usgsParser.js) —
  энергия `10^(1.5 × mag)`, суммируется по стране, затем **`log10`** и min-max.
  Логарифм обязателен: одно M7 даёт в ~5600 раз больше энергии, чем M4.5, и
  при суммировании «сырых» значений одна страна получала бы 100, а все
  остальные — около нуля.
- Страна определяется из текстового поля `place` («113 km E of Kokopo, Papua New Guinea»)
  по словарю имён. Совпадение ищется **от длинных названий к коротким и только
  по границам слов**, иначе «Nigeria» матчилась как Нигер, «Somalia» как Мали,
  «Romania» как Оман.

### 2.5 Pandemic — пандемический риск (20 %)

Парсер: [`whoParser.js`](backend/src/parsers/whoParser.js), три источника,
каждый нормализуется отдельно, затем взвешивается:

```
pandemic = 0.40 × INFORM(epidemic) + 0.35 × WHO DON + 0.25 × ReliefWeb(эпидемии)
```

- **INFORM epidemic** (0–10 → 0–100) — структурная уязвимость: система
  здравоохранения, способность реагировать. Единственный источник со
  сплошным покрытием (191 страна).
- **WHO Disease Outbreak News** — официальные оповещения ВОЗ.
  RSS-фид отключён ВОЗ (отдаёт 404), используется OData-эндпоинт
  `who.int/api/news/diseaseoutbreaknews` (максимум `$top=100`).
  Затухание с периодом полураспада 180 дней, события уровня PHEIC получают
  коэффициент ×2.0.
  Страна извлекается сканированием **всего заголовка**: ВОЗ использует любые
  разделители (`disease- Ethiopia`, `A(H5N2)-Mexico`, `virus, DR Congo & Uganda`),
  а в названии болезни бывает дефис (`vaccine-derived poliovirus type 1- Israel`),
  поэтому разбиение по разделителю не работает. Названия болезней, содержащие
  топоним (`Crimean-Congo`, `Middle East respiratory syndrome`, `Guinea worm`),
  вырезаются до поиска. Заголовки уровня `Global situation`, `Multi-country`,
  `Region of the Americas` распознаются как «без страны» и пропускаются.
- **ReliefWeb epidemics** — только `ongoing` за 6 месяцев, период полураспада
  90 дней, вес по болезни (Эбола/Марбург 3.0, холера 1.8, корь 1.1 …).

## 3. Конвейер обновления

[`backend/src/cron/weeklyUpdate.js`](backend/src/cron/weeklyUpdate.js) — каждый понедельник 06:00 UTC.

```
1. Параллельная загрузка источников (Promise.allSettled)
2. Сборка Map<iso2, значение> по каждому измерению
3. Нормализация / смешивание структурных и событийных компонент
4. score = compositeScore(dims) с весами по умолчанию
5. UPSERT в risks (одна строка на страну и дату) + сброс кэша
```

### Поведение при отказе источника

Пустой ответ источника **не означает «риска нет»**. Поэтому:

- если упал источник измерения — для этого измерения берётся **последнее
  известное значение** из `latest_risks` (перенос вперёд), а не ноль;
- если упали одновременно INFORM и все источники конфликта — обновление
  **прерывается без записи в БД**;
- страны, которых нет в `countries`, пропускаются (лог `skipped`).

### Ручной запуск

```bash
docker exec safety-api node -e "require('./src/cron/weeklyUpdate').runWeeklyUpdate().then(()=>process.exit(0)).catch(e=>{console.error(e);process.exit(1)})"
```

## 4. Хранение и выдача

- Таблица `risks` — история по странам и датам; колонка `score` пишется cron'ом.
- View `latest_risks` — последняя строка на страну (`DISTINCT ON`), включает
  `conflict, disaster, food, seismic, pandemic, score`.
- Роуты `map`, `top10`, `safety` пересчитывают балл на лету через `scoreService`,
  а не читают `risks.score` — чтобы строки, записанные прежней формулой,
  ранжировались согласованно с остальным API.
- Кэш Redis не обязателен: при недоступности запросы идут напрямую в БД
  (`enableOfflineQueue: false`, иначе `ioredis` копит команды и запрос виснет).

### Исключения из рейтинга

Несуверенные территории не покрываются INFORM / World Bank / UCDP как
отдельные субъекты: у них 4 из 5 измерений равны нулю, и они занимали бы
первые места «самых безопасных». Список исключений — в
[`backend/src/routes/customWeights.js`](backend/src/routes/customWeights.js)
(Гонконг, Макао, территории США, Франции, Великобритании, Дании, Нидерландов).
На карте они по-прежнему отображаются.

Страны без строки в `latest_risks` получают `score: null`, `has_data: false`
и заливаются серым — «нет данных», а не «безопасно».

## 5. Состояние источников

| Источник | Измерение | Покрытие | Доступ |
|---|---|---|---|
| INFORM Risk 2026 | disaster, seismic, pandemic | 191 страна | открытый XLSX |
| UCDP GED + candidate | conflict | ~103 страны с потерями | открытый CSV, CC BY 4.0 |
| World Bank SN.ITK.DEFC.ZS | food | ~163 страны | открытый API |
| USGS M4.5+ | seismic (события) | ~84 места за 30 дней | открытый GeoJSON |
| WHO DON (OData) | pandemic | по оповещениям | открытый API, `$top` ≤ 100 |
| ReliefWeb | disaster, pandemic | по событиям | **нужен `RELIEFWEB_APPNAME`** |
| ACLED | conflict (резерв) | — | Cloudflare блокирует серверные IP |

Парсеры `gtdParser.js`, `gdeltParser.js`, `wriParser.js`, `gfsiParser.js`
присутствуют в репозитории, но **не подключены** к конвейеру.

## 6. Известные ограничения

1. **Min-max для conflict и food.** Шкала относительна к худшей стране:
   если ситуация в стране-экстремуме изменится, сдвинутся баллы всех
   остальных. Структурные компоненты (INFORM) от этого свободны.
2. **Conflict без поправки на население.** Абсолютное число погибших:
   крупная страна выглядит опаснее малой при одинаковом уровне насилия.
3. **UCDP считает потери по месту событий.** Страна-агрессор баллов не
   получает — война отражается в данных страны, на территории которой идёт.
4. **Food отстаёт на 2–3 года** и имеет нижний порог 2.5 %: развитые страны
   после нормализации получают ноль.
5. **Нет измерений, важных для путешественника:** уличная преступность
   (UNODC), ДТП (WHO), travel advisories, качество здравоохранения (GHS Index),
   верховенство права (WGI).
6. **Территории.** Исключены из рейтинга списком, а не по качеству данных.

## 7. Направления развития

- Заменить min-max на фиксированные абсолютные якоря (например, для conflict:
  `0 → 0`, `1 смерть/100 тыс. → 50`, `10/100 тыс. → 100` по log-шкале) —
  тогда баллы сопоставимы между запусками и историей.
- Conflict на 100 тыс. населения (World Bank `SP.POP.TOTL`).
- Winsorize по 95-му перцентилю перед нормализацией.
- Новое измерение Crime (UNODC homicide rate).
- Подключить GTD (терроризм) к conflict.
- Travel advisories как отдельный бейдж на карте, вне формулы.
- Показывать покрытие источников в карточке страны («3 из 5 источников»).
